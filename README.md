# Parser Bot for meteo.ru / AISORI-M

Проект теперь разведен на две части:

- `бот-загрузчик` тянет данные из AISORI-M, нормализует их и складывает в локальное хранилище;
- `витрина` показывает уже собранные ряды, позволяет руками дернуть обновление по индексу станции и сразу перерисовывает графики;
- `справочник станций` строится из PDF-каталога ВМО и дает поиск по индексу, названию и карту с координатами.

## Что Уже Работает

- месячная температура воздуха;
- месячная относительная влажность;
- месячные осадки;
- месячная упругость водяного пара;
- месячный дефицит насыщения водяного пара;
- суточная средняя температура воздуха;
- суточная влажность;
- суточный дефицит насыщения водяного пара;
- суточные осадки;
- ручное обновление по индексу станции;
- локальный справочник станций по PDF-каталогу ВМО;
- карта станций в Streamlit;
- хранение нормализованных данных в SQLite;
- красивые графики в Streamlit;
- проверка периода запроса по жизненному циклу станции перед отправкой в AISORI-M;
- отдельная вкладка-заготовка для матриц переходных кривых по локальным XLS-файлам.

Ограничение, подтвержденное живой проверкой 28 марта 2026:

- прямой источник для `радиационного показателя` в доступных разделах AISORI-M под этой учетной записью не найден;
- источники `Метеопараметры атмосферы` и `Метеопараметры в пограничном слое атмосф.` либо не дают параметров, либо не содержат проверенные станции вроде `27612`;
- поэтому матрицы по радиации пока можно только разбирать из ваших XLS-файлов, но не строить автоматически из новой выгрузки AISORI-M.

## Установка

```bash
conda activate bot_env
pip install -r requirements.txt
playwright install chromium
```

## Конфиг

Скопируйте пример:

```bash
cp config/datasets.example.json config/datasets.json
```

Заполните в `config/datasets.json`:

- `credentials.username`
- `credentials.password`
- `credentials.email`

Для dashboard этот же конфиг используется как источник учетных данных.

## Справочник Станций

Сборка локального JSON-справочника из PDF:

```bash
conda activate bot_env
PYTHONNOUSERSITE=1 PYTHONPATH=src python -m parser_bot.cli build-station-catalog \
  --pdf-path /home/user/Downloads/Каталог_Температура_воздухамесячные_данные.pdf \
  --output-path data/stations/monthly_temperature_station_catalog.json
```

После сборки в справочнике доступны:

- `Индекс ВМО`
- `название станции`
- `широта / долгота`
- `высота метеоплощадки`
- `год начала наблюдений`
- `примечание`

## Бот

Разовый запуск всех наборов из конфига:

```bash
conda activate bot_env
PYTHONNOUSERSITE=1 PYTHONPATH=src python -m parser_bot.cli run-once
```

Ежедневный запуск:

```bash
conda activate bot_env
PYTHONNOUSERSITE=1 PYTHONPATH=src python -m parser_bot.cli run-scheduler
```

Ручное обновление одной станции по индексу:

```bash
conda activate bot_env
PYTHONNOUSERSITE=1 PYTHONPATH=src python -m parser_bot.cli refresh-station \
  --station 27612 \
  --datasets monthly_temperature monthly_humidity monthly_precipitation monthly_vapor_pressure monthly_vapor_pressure_deficit daily_temperature daily_humidity daily_vapor_pressure_deficit daily_precipitation \
  --year-from 2020 \
  --year-to 2024 \
  --month-from 1 \
  --month-to 1 \
  --day-from 1 \
  --day-to 15
```

## Визуализация

Запуск витрины:

```bash
conda activate bot_env
PYTHONNOUSERSITE=1 PYTHONPATH=src streamlit run src/parser_bot/dashboard_app.py
```

Что есть в витрине:

- поиск станции по индексу и названию;
- выбор станции из локального справочника;
- карта станций по PDF-каталогу ВМО;
- ввод индекса станции;
- кнопка обновления данных из AISORI-M;
- проверка, не выходит ли запрос за период работы станции;
- кнопка `Все равно отправить запрос`, если пользователь хочет сознательно выполнить спорный запрос;
- карточки последних значений;
- месячные графики по температуре, влажности, осадкам, упругости пара и дефициту насыщения;
- суточные графики по температуре, влажности, дефициту насыщения и осадкам;
- таблица наблюдений;
- журнал обновлений;
- вкладка `Матрицы переходных кривых` с разбором XLS-матриц, их структуры и визуализацией первых найденных матриц переходов.

## Живо Проверено

Станция `27612 Москва, ВДНХ`:

- месячная температура за `2020-2022`;
- месячная влажность за `2022`;
- месячные осадки за `2022`;
- месячная упругость пара за `2020-2022`;
- месячный дефицит насыщения за `2020-2022`;
- суточная температура, влажность, дефицит и осадки за `2024-01-01 .. 2024-01-16`.

Станция `22113 Мурманск`:

- месячная упругость пара за `2020-2022`;
- месячный дефицит насыщения за `2020-2022`;
- суточная температура, влажность и дефицит за `2024-01-01 .. 2024-01-04`.

Примеры реально разобранных значений:

- температура:
  `2020-01 = 0.1`, `2021-07 = 22.2`, `2022-12 = -4.1`
- влажность:
  `2022-01 = 83`, `2022-07 = 65`, `2022-12 = 85`
- осадки по месяцам:
  `2022-01 = 70.0`, `2022-07 = 98.5`, `2022-12 = 131.1`
- упругость пара по месяцам:
  `2020-01 .. 2022-12` реально выгружаются и сохраняются в SQLite
- дефицит насыщения по месяцам:
  `2020-01 .. 2022-12` рассчитывается из месячной температуры и упругости пара
- температура по суткам:
  `2024-01-01 .. 2024-01-16` реально выгружается из `Сроки / SROK8C`
- влажность по суткам:
  `2024-01-01 .. 2024-01-16` реально выгружается из `Сроки / SROK8C`
- дефицит насыщения по суткам:
  `2024-01-01 .. 2024-01-16` реально выгружается из `Сроки / SROK8C`
- осадки по суткам:
  `2024-01-01 = 0.3`, `2024-01-02 = 0.0`, `2024-01-03 = 0.0`
